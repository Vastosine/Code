# 学习者画像（教练用）

> 目的：给题、定节奏、判断卡住时该不该介入。**每次 `start` 前读这一页。**
> 数据来源：2021–2024 的 OI 材料（`OI/others/`）、2026-10~11 的 CF 训练日志、2026-11-02 的自述。

## 一、动机类型：理解型 + 造物型

| | 表现 | 证据 |
|---|---|---|
| **理解型** | 最强的成就感来自「我把一堆不懂的东西自己搞懂了」，不是排名 | 2021 营后一个月重建 26→45 个文件 |
| **造物型** | 初学时的驱动是「写出来的东西能跑」 | 13 岁写《化学大战》v0.0→v0.4：外置配置（`formal.txt` / `.csv`）、版本号、输入校验、`conio.h` 即时按键 |

**推论**：给他「解出难题」的奖励不如给他「造出一个能跑的东西」。

## 二、失败模式：期望落差 → 放弃（不是难度本身）

| | 2021 营（13 岁，基础班） | 2022 营（14 岁，提高班） |
|---|---|---|
| 进营时的自我期望 | 零（连 DFS 都不会） | **高（初三，实力巅峰）** |
| 被灌的量 | 栈/队列/…/线段树 | 大量高难算法，几分钟一道 |
| 营后一个月代码量 | **20 个文件 + 自写游戏** | **2 个文件（1 天）** |
| 结果 | 重建成功，兴趣上升 | 复习几天 → 放弃 → 国庆集训后逐渐退出 |

**结论：燃料不是「被挑战」，是「我能推进」的连续证据。**
**触发放弃的不是「我不会」，是「我不该不会」。**

## 三、给题规则（硬性）

1. **一跳半，不是三跳**：难度增长略快于能力。
2. **永远配一条退路**：任何难题旁边放一道同类的低一档题。
3. **卡 90 分钟无进展 → 换同类低一档**（换入口，不是放弃）。**当天必须有「我做出来了」的东西。**
4. **不做限期营**，做专题窗口（1–2 周，节奏自己定）。拒绝「一次性灌大量 + deadline」。
5. **比赛后必须补题**：把失败转成小胜利。补题比刷题重要。

## 四、方向倾向：系统 / 造工具，不是纯算法研究

- 快反馈、有实感、能跑起来 → 系统、基础设施、工具链、量化
- 纯算法研究**降级**：产出是论文，没有「能跑」的实感
- 这也解释了对「读研」没感觉：若只要文凭，那是理性选择；若指望满足感，它给不了

### 表达偏好（2026-11-04 本人要求）

> 原话：「下次能不能直接输出公式而不是 latex 表达式？」
>

> **2026-11-04 12:00 更正：渲染可用，改用 `$…$`。** 本人确认界面能渲染 LaTeX，所以：

## 八、关键修正（2026-11-02 深夜）：失败模式的真正变量

**不是「难度」也不是「期望落差」，是「有没有一个可运行的参照物」。**

| 事件                 | 可运行的参照物                      | 结果                     |
| ------------------ | ---------------------------- | ---------------------- |
| 2021 营后（13 岁，基础班）  | 有 —— 自己从零写，每行都能跑             | ✅ 一个月重建（26→45 个 cpp）   |
| **2022 提高营（14 岁）** | **没有** —— 只有听不懂的课            | ❌ 复习几天 → 放弃 → 国庆集训后退出  |
| **2026 AI 写模组**    | **有** —— AI 给了 3000 行完整可运行代码 | ✅ **两周自己重写并改进，3975 行** |

**机制**：能跑 → 差距变成「待填的空白」（可操作）；不能跑 → 差距变成「我不懂」（不可操作）。

## 九、manim 视频（2026-11-02 检视）

**《一道物理题引发的思考》** · B 站 UP「余弦·定理」· 1920×1080 / 30fps / **4 分 30 秒** / 8100 帧。

**内容**：初三遇到的一道「额定功率汽车启动」题（附 v-t 图），做成三档递进的 ODE 族：

| 阻力 | 方程 | 解 |
|---|---|---|
| 常数 `f` | `dt = -(m/f)dv + (mP/f)/(P-fv)dv` | 对数 |
| `kv` | `P/v - kv = ma` | `v=√(1-e^{-2t})` ⇔ `t=-½ln(1-v²)` |
| `kv²` | `P/v - kv² = ma` | `t = -⅓ln(1-v) + ⅙ln(1+v+v²) - (1/√3)arctan((1+2v)/√3)` |

**独立核验（教练）**：令 `a=∛(P/k)`，`P-kv³ = k(a-v)(a²+av+v²)`，部分分式系数 `1/(3a)`、`1/(6a)`、`1/(√3a)`，归一化 `a=1` 后与视频第三行**逐项一致**。数学正确。

**水平定位**：需要微分方程建模 + 三次差因式分解 + 有理函数积分（不可约二次因式 → arctan）+ **无量纲化**。最后一步不是解题必需，是为了「看清三个解的结构」——题解完之后还继续做的事。

**意义**：
- **理解型动机的最纯样本** —— 一个初三点题，无人要求，做了 4.5 分钟视频
- **从「给机器用」扩展到「给人用」** —— 需要判断观众会在哪里卡住（分镜从常数阻力起步逐档加难，而不是甩答案）

## 十一、✅ 有效的复习方式：短时高频 + 立即验证（2026-11-05 实测）

**证据**：线代随堂测验前只有 1 小时，做的事是 —— **默写 7 个公式（20 min）→ 5 道题（40 min）→ 3 条自检清单**。**没有通读教材**。结果 **100 / 100**。

**对照反例**：11-04 英语听写硬扛 20 分钟（材料过难）→ 效率极低，全部推倒重来。

> **规则：给他复习材料，优先「默写 + 做题 + 自检」，不要「通读 / 重看笔记」。**
> 他的输入速度很快，但**通读的转化率低** —— **输出才是他的学习方式**：写出来、算出来、验一遍。
>
> **操作模板（70 分钟一段）**：
> 1. **公式/定义默写**（20 min）—— 不看笔记写，写完对照
> 2. **3–5 道题**（40 min）—— 限时，覆盖不同题型
> 3. **自检清单**（10 min）—— 把今天犯的错变成 3 条可执行的检查动作
>
> **这比"把这一章看一遍"有效得多**，而且省时间。
